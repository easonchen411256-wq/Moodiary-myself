# Moodiary

Moodiary 是一款以隐私为先的情绪日记产品。它帮助用户把难以命名的感受写下来，在不评判的前提下回看自己的情绪变化，并通过可选的分析功能发现值得继续观察的生活线索。

在线体验：<https://easonchen411256-wq.github.io/moodiary-web/>

> 本仓库用于 GitHub Pages 部署 Flutter Web 构建产物。Flutter/Dart 源码、测试与跨平台工程保存在 Moodiary 开发工程中；本仓库中的 JavaScript、资源和 `canvaskit/` 文件均为自动生成的发布文件，请勿直接编辑。

## 一、产品理念

### 核心价值主张

Moodiary 的核心价值是“让情绪更容易被表达，也更容易被理解”。产品不要求用户先把感受分析清楚，而是从一句话、一个片段或一次对话开始，逐步形成可回看的个人情绪记录。

- **留住此刻**：降低记录门槛，让用户可以用自然语言、语音或图片留下当下感受。
- **看见轨迹**：把分散的记录组织成时间线、趋势和主题，帮助用户观察自己的节奏。
- **温柔回应**：提供非评判式的提示与可选 AI 洞察，帮助用户继续思考，而不是替用户下诊断或结论。
- **隐私优先**：尽量优先保存在当前设备；需要 AI 服务时由用户自主选择分析方式和配置。

### 设计理念

1. **先表达，后理解**：记录界面首先支持倾诉和描述，不强迫用户立即解释原因。
2. **低打扰、可持续**：采用清晰留白、柔和色彩和渐进式信息层级，适合每天短暂使用。
3. **线索而非判定**：趋势和洞察用于辅助觉察，界面明确区分记录事实、观察线索与个人解释。
4. **从抽象回到原文**：洞察可以回到相关记录，用户始终能够核对信息来源。
5. **可控的智能化**：本地规则分析与 AI 大模型分析可以切换；智能功能不应削弱用户对数据和节奏的控制。

### 要解决的问题

日常情绪往往发生得快、表达得慢。用户可能知道“今天不太好”，却难以描述具体发生了什么；单次记录又很难看出睡眠、工作、人际互动和时间节律之间的长期联系。Moodiary 通过低门槛记录、结构化回顾和温和洞察，帮助用户：

- 在情绪发生时留下可理解的线索；
- 在一段时间后辨认反复出现的状态、主题和触发情境；
- 用自己的记录支持复盘和小步调整，而不是依赖即时判断；
- 在需要时获得辅助性 AI 反馈，同时保留隐私与分析方式的选择权。

### 目标用户

- 想培养稳定记录习惯、但不喜欢复杂表格的个人用户；
- 希望理解压力、睡眠、工作或人际关系与情绪变化之间联系的人；
- 需要低打扰反思工具的学生、研究者、创作者和知识工作者；
- 关注本地优先、希望自行决定是否使用 AI 的隐私敏感用户。

Moodiary 是自我记录与觉察工具，不替代医疗诊断、心理治疗或危机干预服务。

## 二、新界面功能文档

### 1. 首页（Landing）

**用途**：介绍 Moodiary 的定位、记录方式、情绪轨迹和洞察理念。

**使用方式**：打开网页后浏览产品简介；点击“写下此刻”进入记录流程，点击“进入我的空间”进入应用总览；通过顶部导航可查看“功能”页面。

**适用场景**：首次了解产品、向他人介绍 Moodiary，或准备开始第一条记录。

### 2. 功能介绍页（Features）

**用途**：集中展示“留住此刻、看见轨迹、温柔回应”等产品能力，并说明记录、趋势与洞察之间的关系。

**使用方式**：从首页导航进入，按页面区块阅读；使用页面底部行动按钮直接开始记录或返回总览。

**适用场景**：新用户熟悉产品边界，或在选择是否启用智能分析前了解功能范围。

### 3. 顶部导航与响应式页面壳层

**用途**：在桌面和窄屏布局中提供统一的品牌、导航、返回和行动入口。

**使用方式**：桌面端使用顶部导航切换页面；窄屏端使用“打开导航”菜单；品牌标识可返回首页，主要行动按钮可快速进入记录或个人空间。

**适用场景**：跨设备浏览、从任意页面快速切换功能，或在移动宽度下继续使用网页。

### 4. 今日总览（Dashboard）

**用途**：展示近期状态、近 7 日概览、连续记录、本月记录、状态变化和最近的心绪。

**使用方式**：从“进入我的空间”或应用导航进入；查看摘要卡片和趋势提示；点击“记录此刻”“心灵对话”“查看这条线索”进入相应操作。

**适用场景**：每天打开 Moodiary 时快速了解近期状态，或决定下一步是记录、回顾还是继续探索某条线索。

### 5. 记录此刻（Record）

**用途**：记录当前发生的事情、身体和情绪感受，并形成可回看的日记条目。

**使用方式**：输入文字，可按需要添加情绪信息、标签和补充内容；可使用语音入口或图片入口；使用“保存草稿”暂存未完成内容，使用“保存记录”完成提交。

**适用场景**：即时记录情绪、完成一次事件复盘、保存灵感或在睡前整理当天感受。

### 6. 分析方式选择

**用途**：决定记录内容如何获得辅助性情绪分析。

**使用方式**：在记录流程中选择“本地规则”或“AI 大模型”；本地规则无需网络和 API Key，AI 大模型使用“我的空间”中保存的模型配置；切换后可点击“应用并重新分析”。

**适用场景**：离线记录、隐私敏感场景优先使用本地规则；需要更丰富语言理解时再选择 AI 分析。分析方式可随时切换。

### 7. 心灵对话

**用途**：以更自然的对话方式帮助用户开始表达、补充事件背景和整理当下感受。

**使用方式**：从今日总览点击“心灵对话”进入；根据提示逐步回答，不必一次写完整篇日记；结束后可将对话内容整理为记录。

**适用场景**：不知道如何下笔、只想先说几句，或希望通过提问梳理一件具体事情。

### 8. 心绪轨迹（Timeline）

**用途**：按时间回看历史记录，观察记录之间的连续性、主题和上下文。

**使用方式**：从应用导航进入；滚动浏览记录，按页面提供的条件筛选或查找；点击具体记录查看详情，也可从记录继续书写。

**适用场景**：回顾某段时间、寻找情绪变化的转折点，或在分析结果中回到原始记录核对上下文。

### 9. 趋势图谱（Analysis）

**用途**：用图表和摘要呈现一段时间内的情绪变化、时间节律和整体状态。

**使用方式**：进入“趋势图谱”查看心绪趋势、近 30 日概览、早晨/下午/夜晚等时段信息；通过“查看内在洞察”或“回看心绪轨迹”继续深入。

**适用场景**：周回顾、月度复盘、观察情绪是否随作息或事件变化，以及判断哪些主题值得进一步记录。

### 10. 内在洞察（Insights）

**用途**：把近期记录整理成可继续观察的线索、反复出现的思考方式和下一步小练习。

**使用方式**：查看“本周内在觉察”和“值得留意的线索”；打开每条线索回看来源记录；可使用“导出报告”，或选择一个小练习后带着练习再次记录。

**适用场景**：完成一周回顾、想理解重复出现的情绪模式，或把抽象的觉察转化为一个具体而可执行的小行动。

### 11. 我的空间（Profile）

**用途**：管理个人偏好、记录提醒、回顾范围、AI 分析设置、隐私选项和数据导出。

**使用方式**：进入“我的空间”后可以：

- 设置温和记录提示、每周回顾和记录提醒；
- 选择回应方式和回顾范围；
- 配置 AI 分析模型；
- 设置优先保存在当前设备；
- 将数据导出为 JSON 或可阅读的 PDF；
- 保存设置或执行账号相关操作。

**适用场景**：第一次使用时建立偏好，调整提醒频率，切换 AI 配置，或在更换设备前导出数据。

### 12. 登录与账号入口

**用途**：为需要账号能力的场景提供登录、注册和密码找回入口。

**使用方式**：从“我的空间”或页面行动入口进入登录页；按照表单提示完成登录，忘记密码时使用“忘记密码”流程。

**适用场景**：使用账号相关能力或管理云端数据时使用；仅进行本地记录时可按产品当前配置选择是否登录。

## 使用建议

1. 第一次使用时先写下一条简短记录，不必追求完整。
2. 连续使用几天后再查看“心绪轨迹”和“趋势图谱”，避免只根据一次记录下结论。
3. 将“内在洞察”当作可验证的线索，回到原始记录确认是否符合自己的体验。
4. 对隐私要求较高或无网络时使用本地规则分析；需要 AI 时先在“我的空间”检查模型配置和数据处理提示。
5. 定期使用数据导出功能保留个人记录副本。
